# Kit-Electr-nico-Recordatorio-Conmemorativo-FABLAB-SUMMIT
Kit electrónico con luces secuenciales basado en TLC555CP y CD4017. Diseñado en formato circular con ranura para colgador, permite ser usado como collar luminoso conmemorativo del FABLAB SUMMIT. Los asistentes arman el kit durante el evento como experiencia educativa y participativa
